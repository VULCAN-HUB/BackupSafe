# BackupSafe

**메모리카드 백업 무결성 검증 도구.** 촬영본을 여러 백업 위치로 복사하고, 모든 복사본이 원본과 똑같은지 확인한 뒤에야 카드를 포맷해도 된다고 알려 줍니다.

⚠️ **BETA v0.1 (작업 중)** — Windows x64.

## 주요 기능
- 이동식 드라이브 자동 감지 → 여러 백업 위치로 복사
- 원본과 복사본을 하나하나 대조해 **정상 / 누락 / 손상** 3분류
- 전부 정상일 때만 포맷 안전 안내 + 일괄 이름 변경 활성화
- 촬영일(EXIF) 기준 정렬 · 패턴 이름 변경 · 결과 CSV

## 다운로드
[Releases](https://github.com/VULCAN-HUB/BackupSafe/releases/latest) 에서 `BackupSafe-0.1.0-portable.exe` 를 받아 실행하세요. **설치 불필요(포터블).**

## 사용법
1. 메모리카드를 꽂고 BackupSafe 실행 — 카드가 자동으로 잡힙니다
2. 백업 위치를 하나 이상 고르고 **복사**
3. 검증 결과가 모두 **정상**이면 포맷 안내가 뜹니다. 필요하면 이름 일괄 변경
